# 🔐 PasswordChecker-Assembly

This is a simple x86 Assembly program written in 16-bit real mode that checks a user-entered password against a predefined password (`mypassword`) using **signed conditional jumps**.

## 🧠 Features
- Takes password input from the user
- Compares it with the correct password stored in memory
- Prints **Password Matched** or **Password Not Matched**
